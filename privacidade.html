Privacidade 🔐

Seus registros de ciclo, humor e bem-estar são pessoais. Aqui você controla os dados que o ELA mantém neste aparelho.

Como está hoje

Esta versão do ELA salva os registros no armazenamento local do navegador. Google Login e sincronização Supabase ainda não estão ativos no aplicativo principal.

Quando a sincronização for ativada, cada conta deverá acessar somente os próprios dados por políticas RLS no banco.

Exportar meus dados

Crie uma cópia JSON dos registros locais para guardar ou transferir.

Apagar dados deste aparelho

Remove os dados locais usados pelo ELA neste navegador. Esta ação não pode ser desfeita.

Princípios do ELA

• Coletar apenas o necessário para as funções escolhidas pela usuária.
• Não tratar previsões de ciclo como diagnóstico ou método contraceptivo.
• Não expor chaves administrativas do banco no navegador.
• Dar à usuária meios claros de acessar, exportar e apagar seus registros.
